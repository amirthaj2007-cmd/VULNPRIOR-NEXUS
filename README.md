VULNPRIOR NEXUS — Website publishing package

To publish this dashboard and get a shareable public link:
1. Extract this ZIP file.
2. Open https://app.netlify.com/drop in your browser.
3. Sign in or create a Netlify account if prompted.
4. Drag the extracted folder named VULNPRIOR-NEXUS-SHARE-SITE onto the page (or select the folder when prompted).
5. Wait for deployment. Netlify will give you a public URL ending in netlify.app.
6. Share that public URL with your teachers/friends.

Note: The HTML dashboard runs in the browser. Any features requiring live internet lookups need an internet connection. This package does not publish the full Python/Streamlit backend.
